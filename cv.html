A file-based second brain with decay-tiered memory keeps context across sessions; a learning loop reads chat transcripts, infers my intent and proposes rule changes for my approval; scout agents research questions and report on review boards; quota-aware model routing uses a cheaper model by default and the strongest one for design; a phone-readable review hub lets me approve work on the move.

Productised. Packaged as ThoughtSignal under my Troupe Consulting brand; a first external pilot with a founder is underway.

ClickQE — an AI-powered test platform I built and ownpersonal project, own time; later integrated with the QE framework at the sportswear brand

Problem. A green run did not show what was actually observed.

Guard-and-judge harness and PROOF. qe.guard sets constraints before an agent acts; qe.judge scores confidence and keeps append-only audit trails. Every run emits PROOF (Proof of Observed Functionality), which reviewers read in Allure.

AI across the test lifecycle. From the linked architecture and a portal of defined use cases, AI generates test cases and starts automating them. Pull requests are reviewed in Copilot agent mode against a 20-criterion, 100-point rubric. For k6 we judged AI-generated code not good enough, so we ported the functional Playwright specs to k6 browser specs, reviewed against eight written guardrails.
