# Install Broman OS on an Android tablet or phone

Broman OS (trial) is a web app. Chrome on Android can install it, so it gets its own icon and opens full-screen like any app. Tested for a Xiaomi Pad 6 (HyperOS, Chrome) and phone widths.

## Install

1. On the tablet, open the Broman OS trial page in **Chrome**. Use the address you were given for the app itself, not a download page.
2. Wait a few seconds so the page can store itself for offline use.
3. Tap the Chrome menu (three dots, top right), then **Install app**. If you see **Add to Home screen** instead, tap that and then **Install**.
4. Open **Broman OS** from the home screen or the app drawer. It opens full-screen, with no address bar.

If the menu shows neither entry: check that you are in Chrome (not a link preview inside another app), that the address starts with `https://`, and reload once.

## What works offline

After the first load the whole trial is stored on the tablet. With no network you can still use:

- Start here, with Bosun, the guided run
- Dashboard, Inbox (reading), Decisions, Workflows (the sample workflows), Second brain and Usage

Your counters and anything you save stay in this browser on this tablet. Clearing Chrome's site data for this app clears them.

## What needs a computer

- Adding or changing feeds, capturing items, and the AI news cards on Decisions need the local server, which runs on a computer (see `INSTALL-WITH-YOUR-AI.md` in the zip). The tablet cannot run it. Those screens say so.
- The builder tools on Workflows are locked in the trial.

## Updates

When a new version is published, the next time you open the app online it stores the new files and removes the old ones. Close and reopen the app once to see it.

## Remove it

Touch and hold the app icon, then **Uninstall** (or **App info**, then **Uninstall**).
